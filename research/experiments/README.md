# Research experiments

This tree records reproducible research evidence and remains separate from `src/mong_nhiem/`.

- `baselines/` establishes comparison/reference evidence; the completed, frozen baseline is [MN-002 model qualification](baselines/mn-002-model-qualification/README.md).
- `prototypes/` holds exploratory research used to test new hypotheses or approaches; [MN-003 Effective Context Capacity](prototypes/mn-003-effective-context-capacity/README.md) has completed its bounded direct-context measurement and synthesis phase, beginning with [ECC-001 Context Retrieval](prototypes/mn-003-effective-context-capacity/experiments/ecc-001-context-retrieval/README.md).
- [MN-004 State Representation Intervention Design](prototypes/mn-004-state-representation-intervention/README.md) is completed and frozen for its globally indexed state-transition ledger hypothesis. Its final valid v5 comparison improved Llama 8k exact final-state accuracy from `0/24` untreated to `7/24` ledger but did not meet either frozen support threshold (`>=12/24`, delta `>=+8/24`), so the canonical verdict is `unsupported_no_effect_or_insufficient_effect`; Gate D promotion was not earned. The 2k reference remained within its frozen no-harm margin, while Qwen control was `control_not_qualified`.
- [MN-005 State Tracking Intervention Selection](prototypes/mn-005-state-tracking-intervention-selection/README.md) has frozen [Gate A](prototypes/mn-005-state-tracking-intervention-selection/gate-a-hypothesis.md), retained its immutable [Gate B v1 contract](prototypes/mn-005-state-tracking-intervention-selection/gate-b-measurement-contract.md), and frozen a narrowly repaired [Gate B v2 contract](prototypes/mn-005-state-tracking-intervention-selection/gate-b-v2-measurement-contract.md) for a target-aware, model-generated reconstruction artifact passed literally between two fresh model calls. `attempt-0001` remains `experiment_invalid` because the v1 active-control artifact exceeded its v1 Stage A budget; v2 preserves the artifact and causal question while repairing that static fit condition. `attempt-0002` is the canonical first-valid Gate C v2 attempt and its frozen result is `inconclusive` (`1/6` Arm C versus `0/6` active control, `D=+1`). No architecture is promoted and no replacement efficacy attempt is authorized.

- [MN-006 Distributed State Integration](prototypes/mn-006-distributed-state-integration/README.md) has completed Design Gate B, deterministic infrastructure, and a 64-pair / 128-prompt inventory. Its untreated Llama [attempt-0001](prototypes/mn-006-distributed-state-integration/reports/mn-006-attempt-0001.md) is protocol-valid but has `0/32` contiguous and `0/32` interleaved exact correctness in both profiles because all 128 outputs are malformed under the frozen parser. The separate grammar-constrained [attempt-0002](prototypes/mn-006-distributed-state-integration/reports/mn-006-attempt-0002.md), prospectively authorized by the [Response-Channel Gate](prototypes/mn-006-distributed-state-integration/response-channel-gate.md), is also protocol-valid with `16/32` contiguous and `16/32` interleaved exact correctness in both profiles: all outputs parse but every response is `INVALID`. Both attempts are `no_usable_locality_failure_signal_under_v1_baseline`; no treatment was tested.

- The static [Label-Selection Causal Gate](prototypes/mn-006-distributed-state-integration/label-selection-causal-gate.md) preserves those immutable baseline attempts; its resulting D1 direct-state neutral-label mapping diagnostic is protocol-valid / `fixed_label_preference_supported` (`A` for all 16 requests, no grammar-order disagreements), so D2 remains unauthorized. The subsequent [Output-Selection Minimality Gate](prototypes/mn-006-distributed-state-integration/output-selection-minimality-gate.md) freezes S0 direct copying and conditional S1 direct relation. Its canonical four-request [S0 run](prototypes/mn-006-distributed-state-integration/reports/mn-006-output-selection-s0-run-0001.md) is protocol-valid / `direct_copy_supported`: both explicit target labels were copied under both grammar orders. Its separately authorized four-request [S1 run](prototypes/mn-006-distributed-state-integration/reports/mn-006-output-selection-s1-run-0001.md) is protocol-valid / `fixed_label_preference_recurred`: all four outputs were `A`, so direct equality/instruction following is not established and D1 cannot be localized specifically to the added mapping-table abstraction. D2 remains unauthorized.

- The [MN-006 diagnostic-branch closure decision](prototypes/mn-006-distributed-state-integration/diagnostic-branch-closure-decision.md) retired the non-diagnostic A/B path. The single direct-state-vector candidate's canonical [18-cell qualification](prototypes/mn-006-distributed-state-integration/reports/mn-006-direct-state-vector-qualification-run-0001.md) is `protocol_valid` / `direct_state_vector_interface_blocked`: Q0 is `9/9`, but Q1 contiguous task-bearing recovery is `1/9`. MN-006 is now formally [completed and closed](prototypes/mn-006-distributed-state-integration/milestone-closure.md) at `measurement_interface_blocked` for the qualified model/runtime. Locality remains unmeasured; retries, alternate interface search, locality execution, D2, perfect-state work, and interventions are unauthorized.

- [MN-007 State Recovery Operating Region](prototypes/mn-007-state-recovery-operating-region/README.md) has frozen its bounded contiguous difficulty landscape and deterministic [materialization contract](prototypes/mn-007-state-recovery-operating-region/materialization-contract.md), then materialized the 108-case static corpus with byte-identical independent regeneration. It will prospectively map a finite latest-state-recovery operating region before any later locality experiment. It is explicitly not an MN-006 retry: no run authority, executor, locality run, intervention, or model evidence exists.
- [MN-008 External State Management](prototypes/mn-008-external-state-management/README.md) freezes [Gate A](prototypes/mn-008-external-state-management/gate-a-hypothesis.md) and [Gate B](prototypes/mn-008-external-state-management/gate-b-measurement-contract.md) for decoupling deterministic state tracking into a host-managed engine, supplying structured state snapshots for downstream conditional/causal evaluation over a Latin Square counterbalanced 4-branch decision matrix.

Each experiment documents its question, scope/non-goals, setup, environment/runtime, inputs/configuration, evaluation, evidence, limitations, and conclusions. A prototype must establish its hypothesis, baseline, variables, metrics, and success criteria before testing an architecture intervention. Keep immutable definitions, selected-run metadata/results, validation outputs, and reports; retain raw diagnostics according to the experiment's retention policy. Promote code into the reusable package only after evidence and an explicit decision.
