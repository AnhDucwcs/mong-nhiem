# Research experiments

This tree records reproducible research evidence and remains separate from `src/mong_nhiem/`.

- `baselines/` establishes comparison evidence; the completed baseline is [MN-002 model qualification](baselines/mn-002-model-qualification/README.md).
- `prototypes/` holds bounded hypothesis tests.

Each experiment documents its question, scope/non-goals, setup, environment/runtime, inputs/configuration, evaluation, evidence, limitations, and conclusions. Keep immutable definitions, selected-run metadata/results, validation outputs, and reports; retain raw diagnostics according to the experiment's retention policy. Future prototype work belongs in `prototypes/`. Promote code into the reusable package only after evidence and an explicit decision.
