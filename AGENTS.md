# Agent guide

Before substantial implementation or design work, read `docs/PROJECT.md`, `docs/ARCHITECTURE.md`, and `docs/CURRENT_STATE.md`.

- Read `docs/DECISIONS.md` before making or changing architectural decisions.
- Read `docs/RESEARCH.md` when planning, implementing, evaluating, or interpreting research experiments.
- Respect recorded architectural decisions; do not treat hypotheses as facts.
- Keep tasks narrow and do not implement roadmap items unless explicitly requested.
- Do not silently promote experimental code into `src/mong_nhiem/`.
- Run relevant tests before finishing.
- Update `CURRENT_STATE.md` after implementation work.
- Update `DECISIONS.md` only for meaningful architectural changes.
