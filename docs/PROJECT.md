# Project

Mộng Nhiễm is intended to become a reusable research engine/library that helps small language models work effectively with knowledge and context spaces much larger than their native context window.

The core research problem is how to make useful information available within a constrained model context without assuming a particular model, retrieval technique, or storage system.

Long term, the library may be integrated into agentic systems, games, chatbots, and local AI applications. Those integrations, as well as research algorithms, model adapters, vector databases, and embedding choices, are explicitly out of scope for this scaffold.
